      What these numbers mean

      An active environment is a distinct random ID observed during a UTC window, not a verified person. Multiple devices, reset IDs, opt-outs, blocked requests and failed sends affect the counts. These are adoption indicators, not an exact population or a guaranteed lower bound.

      Analytics Engine can sample data, especially over longer windows. Sampling can omit activity, and its interval does not provide an error bound. The dashboard flags observed sampling and inconsistent daily, weekly or monthly counts without changing the figures.

      The CLI sends at most one ping per UTC day with an installation ID, version, OS, architecture and command name. Nothing from usage logs, prompts or costs is sent. This page publishes aggregate counts only, never installation IDs. Command breakdowns are omitted because the first command of the day does not represent all command usage.

      Aggregates are generated daily after 00:15 UTC. The public API is cached at the edge until the next aggregate and in browsers for up to five minutes. No page analytics or third-party scripts are used.

      To opt out, run ccusage telemetry disable or set DO_NOT_TRACK=1. Read the collection and storage policy.
