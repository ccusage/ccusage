# AGENTS.md - Documentation

`README.md` covers the site structure, hosting, and commands. This file adds the writing
conventions for changes under `docs/`.

- A guide with a primary screenshot leads with it, immediately after the H1, with descriptive alt
  text and a root-relative path such as `/screenshot.png` for files in `docs/public/`. See
  `guide/daily-reports.md`.
- Cross-link related guides and `guide/json-output.md` where useful.
- Put `<!-- eslint-skip -->` before a markdown code block ESLint should skip.
